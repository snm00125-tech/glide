# Glide 배포

개인용 유튜브 광고 차단기 Glide의 **배포 전용** 저장소입니다. 앱 소스와 서명 키는 들어 있지 않습니다.

- 최신 앱: 1.0.0 — `apk/glide-1.0.0.apk` (폰 앱은 설정 → 정보 → 업데이트 확인으로 자동으로 받음)
- `app.json`: 앱이 확인하는 최신 버전 정보
- `core/`: 앱이 원격으로 받는 페이지 스크립트·필터 (PC 확장의 필터 자동 업데이트도 여기서)
- `extension/`: PC 크롬·엣지 확장 프로그램

## PC 확장 프로그램 넣기
1. 이 저장소를 **Code → Download ZIP**으로 받아 압축을 풉니다.
2. 크롬 `chrome://extensions` (엣지 `edge://extensions`) → **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 풀어 둔 폴더 안의 `extension` 폴더
4. 열려 있던 유튜브 탭은 새로고침

새 버전이 나오면 같은 폴더에 덮어쓰고 확장 프로그램 카드의 새로고침(↻)을 누르면 됩니다.
